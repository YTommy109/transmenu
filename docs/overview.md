# TransMenu プロジェクト概要

## 課題設定

- 個人飲食店が外国人観光客用のメニューを提供できず、オペレーションに時間がかかっている

## 解決案

- 飲食店が用意しているメニューをスマホで写真に撮ると、お店専用の翻訳メニューページが作成される

## 機能詳細

### Phase 1. メニュー写真から英語メニューを作成する

- 基本機能のミニマムな骨格を作る。
- 店舗の識別、ユーザーの識別は行わない。
- web のトップページのみで実現する。

#### 1. メニュー写真撮影機能

- スマートフォンのカメラを使用してメニューを撮影

#### 2. 日本語メニューの抽出

- AI OCR でメニュー画像から日本語を取り出す

#### 3. 英語メニューへ翻訳

- LLM で日本語メニューから英語メニューに翻訳する

### Phase 2. 店舗識別

#### 1. 店舗登録ができる

- 店舗登録すると個別 ID が発行される
- 個別 ID 単位で店舗ページが作成される
- Phase 1 で作った機能は店舗ページに配置される

#### 2. QRコード生成・配布

- お店に貼る QR コードも用意される
- QR コードを読み取ると、お店のページに飛ぶ
- 来店客が簡単にアクセスできる仕組み


### Phase 3. メニューの編集

#### 1. OCR で抽出した日本語メニューを編集できる

#### 2. LLM で翻訳した英語メニューを編集できる

#### 3. 店舗が見るページと来店客が見るページを分離する


## 未来の機能案


### 1. メニュー写真管理機能

- メニュー写真も登録できる
- 写真の追加・編集・削除機能

### 2. 位置情報連携機能

- 写真の EXIF かスマホの GPS から位置情報を取得
- 地図からメニューを見ることもできる
- 地理的な検索・発見機能を提供

### 3. 店舗スタッフ管理機能

- 店長以外のメンバーもメニューのメンテナンスができる
- メンバーは店長が登録する
