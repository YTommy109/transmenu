# OCR ボタンと画像文字抽出機能の追加

## Why

メニュー写真をアップロードする機能は既に実装されているが、画像から文字を抽出する機能がない。ユーザーがメニュー写真からメニュー項目や価格などの情報を手動で入力する必要があり、時間がかかりエラーも発生しやすい。OCR（光学文字認識）機能を追加することで、画像から自動的に文字を抽出し、ユーザーの作業効率を大幅に向上させることができる。

## What Changes

- `MenuPhotoUpload`コンポーネントにOCRボタンを追加
- アップロード済み画像に対してOCR処理を実行できる機能を追加
- 抽出されたテキストを表示するUIを追加
- サーバーサイドでOCR処理を実行するためのAPIエンドポイント（`/api/ocr`）を追加
- OpenAI API（GPT-4 Vision）を使用して画像から文字を抽出
- OCR処理中のローディング状態とエラーハンドリングを実装

## Capabilities

### New Capabilities

- `ocr-text-extraction`: 画像から文字を抽出する機能。
  アップロード済み画像に対してOCR処理を実行し、抽出されたテキストを表示する。
  OpenAI API（GPT-4 Vision）を使用してサーバーサイドで処理される。

## Impact

**影響を受けるコード:**

- `src/components/MenuPhotoUpload.tsx`: OCRボタンとテキスト表示UIを追加
- `app/api/ocr/route.ts`: 新規APIエンドポイント（OpenAI APIを使用して画像から文字を抽出）
- `src/lib/openai.ts`: 既存のOpenAIクライアント設定を利用（変更なし）

**依存関係:**

- 既存の`openai`パッケージを使用（追加の依存関係は不要）
- OpenAI APIキーが必要（既に`OPENAI_API_KEY`環境変数で設定済み）

**パフォーマンスへの影響:**

- OCR処理はOpenAI APIへのリクエストとして実行されるため、ネットワークレイテンシが発生
- 非同期で実行し、ローディング状態を表示
- API呼び出しのコストが発生（GPT-4 Visionの使用料金）

**ユーザー体験:**

- 画像からテキストを抽出する手間が省ける
- 抽出されたテキストをコピー&ペーストで利用可能
