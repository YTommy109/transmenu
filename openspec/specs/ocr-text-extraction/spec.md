# OCR テキスト抽出仕様

## Purpose

アップロード済みのメニュー画像からテキストを自動抽出する機能を提供する。
ユーザーが手動でテキストを入力する手間を省き、作業効率を向上させる。

## ADDED Requirements

### Requirement: アップロード済み画像に対してOCRを実行できる

システムSHALL、既にアップロードされた画像からテキストを抽出できるOCRボタンを
各アップロード済み画像に対して提供する。

#### Scenario: 各アップロード済み画像にOCRボタンが表示される

- **WHEN** ユーザーがアップロード済み画像の一覧を表示する
- **THEN** 各画像アイテムにOCRボタンが表示される

#### Scenario: アップロード済み画像からテキストを抽出する

- **WHEN** ユーザーがアップロード済み画像のOCRボタンをクリックする
- **THEN** システムは画像IDを`/api/ocr`エンドポイントに送信する
- **AND** 抽出されたテキストが表示される

### Requirement: OCR APIがOpenAI Visionを使用して画像を処理する

システムSHALL、`/api/ocr`エンドポイントに送信された画像からテキストを抽出するために
OpenAI API（GPT-4 Vision）を使用する。

#### Scenario: OCR APIが画像IDを受け付ける

- **WHEN** 画像IDを含むPOSTリクエストが`/api/ocr`に送信される
- **THEN** APIはデータベースから画像を取得する
- **AND** 適切なプロンプトと共にOpenAI Vision APIに送信する

#### Scenario: OCR APIが抽出されたテキストを返す

- **WHEN** OpenAI Vision APIが画像の処理に成功する
- **THEN** APIは抽出されたテキストをJSON形式で返す
- **AND** レスポンスにはステータス200が含まれる

#### Scenario: OCR APIがOpenAI APIエラーを処理する

- **WHEN** OpenAI Vision APIがエラーを返す
- **THEN** APIは適切なエラーメッセージを返す
- **AND** レスポンスにはステータス500が含まれる

#### Scenario: OCR APIが画像形式を検証する

- **WHEN** サポートされていない画像形式でリクエストが送信される
- **THEN** APIはエラーメッセージを返す
- **AND** レスポンスにはステータス400が含まれる

### Requirement: 抽出されたテキストがユーザーに表示される

システムSHALL、ユーザーがテキストをコピーできる読み取り可能な形式で
抽出されたテキストを表示する。

#### Scenario: OCR成功後に抽出されたテキストが表示される

- **WHEN** OCR処理が正常に完了する
- **THEN** 抽出されたテキストがテキストエリアまたは類似のコンポーネントに表示される
- **AND** テキストは選択可能でコピー可能である

#### Scenario: OCR処理中にローディングインジケーターが表示される

- **WHEN** OCR処理が進行中である
- **THEN** ローディングインジケーターまたはスピナーが表示される
- **AND** OCRボタンに「処理中...」または類似のテキストが表示される

#### Scenario: OCR失敗時にエラーメッセージが表示される

- **WHEN** OCR処理が失敗する
- **THEN** ユーザーにエラーメッセージが表示される
- **AND** エラーメッセージはユーザーフレンドリーで実行可能である

### Requirement: OCR処理は非ブロッキングである

システムSHALL、ユーザーインターフェースをブロックせずに非同期でOCR処理を
実行する。

#### Scenario: OCR中もUIが応答性を保つ

- **WHEN** OCR処理が進行中である
- **THEN** ユーザーインターフェースは応答性を保つ
- **AND** ユーザーはアプリケーションの他の部分と対話できる
